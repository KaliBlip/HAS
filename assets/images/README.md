Place your application logo image here as `logo.png` (JPEG file).

This project expects the logo at `assets/images/logo.png` and the header and sidebar will reference that path.

If you provided a logo attachment, save it exactly as `logo.png` in this folder. Example (on Windows cmd):

copy C:\path\to\downloaded\logo.png assets\images\logo.png

Or move the file into the folder using Explorer.
